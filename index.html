Bob はコードの作成、既存コードのリファクタリング、さまざまなタスクの実行をサポートするAI搭載のコーディングアシスタントです。カスタムモードや指示を追加することで機能を拡張できます。

Bob は大規模言語モデル（LLM）を使用してリクエストを理解し、アクションに変換します。主な機能は以下のとおりです：

  • プロジェクト内のファイルの読み書き
  • ターミナルでのコマンド実行
  • インターネットの閲覧（有効な場合）
  • Model Context Protocol（MCP）を通じた外部ツールの利用

チャットインターフェースを通じて指示を入力し、Bobが提案したアクションを確認・承認することで操作します。

Bob はさまざまなコーディングタスクをサポートします：

  • 自然言語からのコード生成
  • 既存コードのリファクタリング
  • バグの修正
  • ドキュメントの作成
  • コードの解説
  • コードベースに関する質問への回答
  • 反復作業の自動化
  • 新規ファイル・プロジェクトの作成

以下のデータは Bob で処理しないでください：

  • SPI（機密個人情報）
  • PHI（個人医療情報）
  • 輸出規制対象データ（ITAR、APPなど）
  • 規制対象の金融データ（銀行口座番号、PAN、非公開の財務データなど）

Bob は強力なツールです。責任ある使い方を心がけてください：

  • Bob は間違いを犯す可能性があります。承認前に変更内容を必ず確認してください。
  • Bob はコマンドを実行できます。自動承認を使用している場合は特に注意が必要です。

Bob パネルを開き、チャット入力欄にタスクを入力します。何をしてほしいかを明確かつ具体的に記述してください。

チャット入力エリアのドロップダウンメニューから別のモードを選択するか、/ コマンドを使用して特定のモードに切り替えてください。

ツールは Bob がシステムと対話する手段です。Bob はタスクを完了するために適切なツールを自動的に選択して使用します。ツールを直接呼び出す必要はありません。各ツールの使用時に承認または拒否を求められます。

コンテキストメンションは、ファイル、フォルダ、問題などのプロジェクト固有の情報を Bob に提供する方法です。@ 記号の後にメンションしたいアイテムを入力します（例：@/src/file.ts、@problems）。

はい、Bob はコマンドを実行できます。コマンドの自動承認を有効にしていない限り、各コマンドの実行前に承認を求められます。コマンドの自動承認の使用には十分ご注意ください。

Bob が提案したアクションを承認または拒否することでフィードバックできます。フィードバックフィールドを使用して追加のコメントを入力することもできます。

はい、いくつかの方法でカスタマイズできます：

  • カスタム指示：すべてのモードに共通の指示や、モード固有の指示を設定できます。
  • カスタムモード：カスタマイズされたプロンプトとツール権限を持つ独自のモードを作成できます。
  • Bobルール：プロジェクトのルートにある .bob/rules/ フォルダにマークダウンのルールファイルを作成して追加ガイドラインを設定できます。
  • 設定：自動承認、差分編集などの各種設定を調整できます。

はい、Bob には有効にすることでアクションを自動的に承認するいくつかの設定があります。

MCP は Bob が外部サーバーと通信するためのプロトコルです。カスタムツールやリソースを追加することで Bob の機能を拡張できます。

はい、独自の MCP サーバーを作成して Bob にカスタム機能を追加できます。

以下を確認してください：

  • APIキーが正しく、期限切れになっていないか確認する
  • インターネット接続を確認する
  • VS Code を再起動する

Bob は VS Code の標準ファイル編集機能を使用しています。標準の「元に戻す」コマンド（Ctrl/Cmd + Z）で変更を取り消すことができます。また、チェックポイント機能を使用してファイルへの変更を以前の状態に戻すこともできます。
