## 背景・目的

`qa.md` に記載されている IBM Bob のよくある質問（FAQ）コンテンツをもとに、バックエンドなしで動作する日本語の静的FAQサイトを作成する。ユーザーが任意のブラウザで `index.html` を開くだけで利用できる、シンプルかつ整ったUIを提供する。

## 現在の挙動

`qa.md` にFAQコンテンツ（英語）が存在するが、Webサイトは存在しない。

## 期待する挙動

* ブラウザで `index.html` を開くとFAQサイトが表示される
* FAQコンテンツが日本語に翻訳されて掲載されている
* カテゴリフィルタでカテゴリを絞り込める
* キーワード検索で質問・回答を絞り込める
* 質問をクリックするとアコーディオン形式で回答が展開・折りたたまれる

## 主な仕様

### 追加機能（v2）

#### 1. Bobロゴ画像の挿入

* ヘッダー左上（タイトルの左側）に `bob.svg` を表示する
* 表示サイズ: 高さ 40px（アスペクト比維持）
* 画像には `alt="IBM Bob"` を設定する

#### 2. ロゴ画像へのリンク付与

* `bob.svg` を `<a>` タグで囲み、`href="https://www.ibm.com/products/bob"` を設定する
* `target="_blank"` / `rel="noopener noreferrer"` を設定し、新しいタブで開く

#### 3. ヘッダー背景のグラデーション変更（テーマカラー変更）

* ヘッダー背景を単色 `#161616` から、左→右の線形グラデーション `#0f62fe`（IBM Blue）→ `#a56eff`（Purple）に変更する
* `bob.svg` のグラデーション（`linear-gradient`）に準拠

#### 4. ダークテーマの追加

* ヘッダー右上にライト/ダーク切り替えトグルボタンを配置する
* トグルボタンのラベル: ライト時は「🌙 ダーク」、ダーク時は「☀️ ライト」を表示する
* ダークテーマは Carbon Gray 100 に準拠する

  | トークン                  | ライト         | ダーク         |
  | ------------------------- | -------------- | -------------- |
  | `--color-bg`              | `#ffffff`      | `#161616`      |
  | `--color-bg-subtle`       | `#f4f4f4`      | `#262626`      |
  | `--color-bg-hover`        | `#e8e8e8`      | `#353535`      |
  | `--color-border`          | `#e0e0e0`      | `#393939`      |
  | `--color-border-strong`   | `#8d8d8d`      | `#6f6f6f`      |
  | `--color-text-primary`    | `#161616`      | `#f4f4f4`      |
  | `--color-text-secondary`  | `#525252`      | `#c6c6c6`      |
  | `--color-text-placeholder`| `#a8a8a8`      | `#6f6f6f`      |
  | `--color-layer-01`        | `#f4f4f4`      | `#262626`      |
  | `--color-layer-02`        | `#ffffff`      | `#393939`      |
  | `--color-tag-bg`          | `#dde1ff`      | `#dde1ff`      |
  | `--color-tag-text`        | `#001d6c`      | `#001d6c`      |

* テーマ状態はページを再読み込みしても保持しない（セッション内のみ）

### FAQコンテンツ

`qa.md` の全項目を日本語に翻訳して掲載する。カテゴリは以下の4つ：

| カテゴリ (英語)      | カテゴリ (日本語表示) |
| ------------------- | --------------------- |
| General             | 基本情報              |
| Usage               | 使い方                |
| Advanced Features   | 高度な機能            |
| Troubleshooting     | トラブルシューティング |

### 検索機能

* 検索バーに文字を入力するとリアルタイムでFAQを絞り込む
* 質問文と回答文の両方を検索対象とする
* 検索は大文字・小文字を区別しない

### カテゴリフィルタ

* 「すべて」「基本情報」「使い方」「高度な機能」「トラブルシューティング」のボタンを表示
* ボタンをクリックすると該当カテゴリのFAQのみ表示
* 検索とフィルタは AND 条件で組み合わせて動作する

### アコーディオン

* FAQ一覧の各質問をクリックすると回答が展開・折りたたまれる
* 複数の質問を同時に展開できる
* 展開状態はアイコン（▶ / ▼ など）で視覚的に示す

## 制約・非機能要件

* バックエンドなし（静的ファイルのみ）
* 外部CDNの利用は可（Carbon Design System のCSS/JS）
* JavaScriptフレームワーク不使用（バニラJS）
* レスポンシブ対応（デスクトップ優先、スマートフォンでも閲覧可能）

### 操作・画面遷移

* 単一ページ構成（SPA・ページ遷移なし）
* 検索バー入力 → FAQ一覧がリアルタイムに絞り込まれる
* カテゴリボタンクリック → 該当カテゴリのみ表示
* FAQ質問クリック → 回答アコーディオン開閉
* **Bob画像クリック** → `https://www.ibm.com/products/bob` を新しいタブで開く
* **トグルボタンクリック** → ライト/ダークテーマを切り替える

### 表示状態

* **初期表示（ライト）:** 全FAQを表示、テーマはライト
* **ダークテーマ時:** 背景・テキスト・ボーダーが Carbon Gray 100 準拠の値に切り替わる
* **検索・フィルタ一致なし:** 「該当する質問が見つかりませんでした。」と表示
* **アコーディオン閉:** 質問のみ表示
* **アコーディオン開:** 質問＋回答を表示

### 入力・バリデーション

* 検索バー: 特別なバリデーションなし（空文字の場合は全件表示）

### デザイン要件

* IBM Carbon Design System 風デザイン
  * カラー: IBM Blue (`#0f62fe`) をアクセントカラーとして使用。ヘッダー背景はBlue→Purpleグラデーション
  * タイポグラフィ: IBM Plex Sans（CDN経由）
  * レイアウト: グリッドベース、直線的・角ばったコンポーネント
  * **禁止（メインコンテンツエリア）:** 光彩（glow）、丸みを強調した要素（大きな border-radius）、フローティングカード風シャドウ
  * ヘッダー背景のグラデーションは許容（Bob画像カラーに準拠）
* レスポンシブ: デスクトップ（1200px以上）/ タブレット（768px以上）/ スマートフォン（768px未満）
